# Path morph

`gpui::PathMorph` interpolates endpoints and Bézier control points between two
paths with matching command sequences. It supports lines, quadratic and cubic
curves, multiple contours, and open or closed paths.

## Pair paths

```rust,ignore
use gpui::{PathBuilder, PathMorph, point, px};

let mut from = PathBuilder::fill();
from.move_to(point(px(20.), px(40.)));
from.line_to(point(px(80.), px(40.)));

let mut to = PathBuilder::fill();
to.move_to(point(px(20.), px(70.)));
to.line_to(point(px(80.), px(10.)));

let morph = PathMorph::new(from, to)?;
```

Construct the pairing when geometry changes and retain it in the owning view.
Clones share the validated command pairs. Builder transforms are applied before
pairing; fill/stroke styles and dash settings are not retained.

The paths must have the same command kinds in the same order, including contour
beginnings and closure flags. A line does not pair with a quadratic or cubic
curve. Commands generated by `arc_to` must also match after arc conversion.
Non-finite coordinates or incompatible topology return an error at construction.

Contour order, starting vertices and winding should correspond. No automatic
reordering, resampling or reversal is performed. Matching topology alone does
not prevent intermediate self-intersections. Degenerate segments are retained
and can be used to grow a segment from, or shrink it to, a point.

## Draw a frame

```rust,ignore
use gpui::{LineCap, LineJoin, StrokeOptions, rgb};

let style = StrokeOptions::default()
    .with_line_width(4.)
    .with_line_cap(LineCap::Round)
    .with_line_join(LineJoin::Round);
let stroke = morph.stroke(progress, &style)?;
window.paint_path(stroke, rgb(0x8de6f1));
```

Paint inside a canvas paint callback. `fill(progress, &FillOptions)` draws a
filled shape and supports the chosen fill rule, including holes with `EvenOdd`.
Parent clipping, paint color and device scaling use normal GPUI path rendering.

Progress is clamped to `0..=1`; non-finite values return an error. Zero and one
preserve the transformed endpoint geometry. Coordinates interpolate linearly;
the caller supplies easing when desired. Interpolation is not based on arc length.

## Compose with path operations

```rust,ignore
let mut frame = morph.interpolate(progress)?;
frame.scale(1.5);
frame.translate(gpui::point(gpui::px(20.), gpui::px(30.)));
let measured = frame.measure();
let stroke = measured.stroke_range(0.0..reveal_progress, &style)?;
```

`interpolate` returns a `PathBuilder` with the default fill style. It can be
restyled, transformed, measured, or used as an endpoint of another morph.
Reusing the current interpolated geometry as a new start preserves position
continuity when retargeting; velocity continuity remains the caller's responsibility.

Each interpolation builds geometry, and each fill/stroke call tessellates it.
Cache the rendered `Path` when progress and styling are unchanged. The pairing
owns no playback state and requests no frames. Applications control duration,
pause, reverse, progress and easing.

## Example

```sh
cargo run -p gpui --example path_morph
```

The example shows menu/close, download/check, and circle/rounded-square morphs.
Controls provide pause, reverse, endpoint and midpoint selection, and duration.
